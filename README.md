## ▸ How to Use

**1. Download Archive**
Download the latest release package from the **Releases** tab or the download link above.

**2. Extract Files**
Extract all contents of the archive into a single folder on your desktop.

**3. Run Loader**
Run the loader executable as **Administrator**.

**4. Launch & Inject**
Start Delta Force, enter a match, and press `INSERT` or `DELETE` to open the in-game menu.
